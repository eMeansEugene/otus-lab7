Detailed Description

Накопитель команд, реализующий логику формирования блоков.

Поддерживает два режима формирования блоков:

  • статический: блок закрывается по достижении N команд;
  • динамический: блок открывается командой "{" и закрывается парной командой "}", вложенные скобки увеличивают/уменьшают глубину вложенности, но не создают новых блоков.

Accumulator не знает, как готовый блок выводится или сохраняется — он только уведомляет подписанных наблюдателей (см. IObserver).

◆ HandleEof()

void Accumulator::HandleEof ( )

Сигнализирует о завершении входного потока данных.

Если накопитель находится вне динамического блока — незавершённый статический блок принудительно уведомляется. Если EOF наступил внутри динамического блока (глубина > 0) — весь текущий динамический блок отбрасывается без уведомления наблюдателей, согласно требованиям задания.
